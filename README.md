# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE

Step 1:  
     1. Switch on the computer and open Autodesk Fusion 360. 
     2. Select New Design to create a new drawing. 
     3. Click on Create Sketch from the toolbar.
<img width="1027" height="652" alt="Screenshot 2026-11-16 100034" src="https://github.com/user-attachments/assets/783d0615-41cd-4e3a-97ca-e2e30d8c7652" />



Step 2: Select the Sketch Plane 
1. Select the XY plane . 
2. The sketch page will appear on the screen. 
3. Make sure the view is set to Front view.

<img width="402" height="333" alt="Screenshot 2026-11-16 100237" src="https://github.com/user-attachments/assets/fb1cee39-57a4-4730-be7f-e9e62628abab" />



 Step 3: Draw the Outer Circles 
1. Select the Center Diameter Circle tool. 
2. Draw six circles at the required positions as shown in the drawing. 
3. Set the radius of each circle to R15. 
4. Place two circles at the top, two at the bottom and two on the left and right sides.

<img width="527" height="445" alt="Screenshot 2026-11-16 100254" src="https://github.com/user-attachments/assets/8f19bbe5-3d80-42b1-8504-bdb707fb41ff" />


Step 4: Draw the Outer Profile 
1. Use the line tool to connect the outer circles. 
2. Select the arc tool to create curved portions between the circles. 
3. Apply the required radius dimensions, such as R20 and R21, as shown in the 
drawing. 
4. Join all the lines and arcs to form the outer boundary. 
5. Use the Trim tool to remove unwanted portions.

<img width="327" height="587" alt="Screenshot 2026-11-24 203345" src="https://github.com/user-attachments/assets/3b4a5fb8-f750-4c43-b1f3-d5891ce23c4e" />




 Step 5: Draw the Centre Circle 
1. Select the Center Diameter Circle tool. 
2. Draw a circle at the origin of the sketch. 
3. Set its radius to R16. 
4. Draw another concentric circle with a radius of R21 to form the surrounding ring.

<img width="278" height="257" alt="Screenshot 2026-11-24 202705" src="https://github.com/user-attachments/assets/df06ad74-e10c-46fe-9dbc-b742c9957470" />


Step 6: Create the Six Curved Slots 
1. Select the arc tool and draw curved portions around the centre circle. 
2. Use the required outer radius of R32. 
3. Divide the curved portions into six equal sections. 
4. Use the Line tool to connect the inner and outer arcs. 
5. Create six separate curved openings around the centre ring

<img width="431" height="428" alt="Screenshot 2026-11-24 203747" src="https://github.com/user-attachments/assets/ec5b06fc-2944-4f9e-b72e-02a6e763d3d9" />


Step 7: Apply Dimensions 
1. Select the Sketch Dimension tool. 
2. Apply the required radius dimensions to all circles and arcs. 
3. Check the dimensions according to the given drawing.

<img width="846" height="672" alt="Screenshot 2026-11-24 203139" src="https://github.com/user-attachments/assets/d3014eca-d428-4b2a-9b99-43e99a66bc8a" />


Step 8: Finish the Sketch 
1. Check whether all the unwanted lines are removed. 
2. Click on Finish Sketch  to complete the drawing. 
3.Extrude the drawing.

<img width="437" height="408" alt="Screenshot 2026-11-16 110424" src="https://github.com/user-attachments/assets/8e04956e-3a6e-4875-8402-d40d66dec2b0" />


Step 9: Save the Design 
1. Click on the Save option. 
2. Enter a suitable name for the design. 
3. Save the file in the required location. 
4.Create drawing file
